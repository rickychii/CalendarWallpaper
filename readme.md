# Weekly Calendar Wallpaper Generator

A simple Windows Console program developed by **Rickychii** (13/04/2025).  
This program generates a weekly calendar image with the current day highlighted, saves it in the user's picture folder, and sets it as the Windows wallpaper.

## Features

- Generates a weekly calendar image based on the current week.
- Highlights the current day of the week.
- Saves the image in the user's **Pictures** folder.
- Automatically sets the generated image as the desktop wallpaper.
  
## How It Works

1. The program creates a weekly calendar image with the current day highlighted.
2. It saves the image in the user's **Pictures** folder.
3. The image is then set as the desktop wallpaper on your Windows machine.

## Requirements

- **Windows OS** (Tested on Windows 10 and 11).
- .NET Framework 4.8.1.
  
## Usage

1. Download or clone this repository.
2. Compile the program using Visual Studio or any other compatible .NET compiler.
3. Run the executable from your Windows machine.
4. The program will automatically generate the weekly calendar image and set it as your wallpaper.
